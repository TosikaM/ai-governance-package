Guardrails Implied & Operating Mechanism

🔑 Secret & Credential Guardrail (POL-SEC-001)

Scans all staged source code and configuration files using high-entropy regex patterns to detect OpenAI keys (sk-...), Anthropic keys, AWS secrets, and database passwords before they can leave the machine.

Enforcement: If any match is found, the git commit is aborted immediately with exit code 1.

# File: plugins/pre-commit/scan_secrets.py pattern = r'(?i)(api[_-]?key|secret|token|password)[\s]*[:=][\s]*["\']([a-zA-Z0-9_\-]{16,})["\']' if re.search(pattern, diff): print("❌ FATAL: Hardcoded credential detected. Commit rejected.") sys.exit(1)
📜 Manifest Registration Guardrail (POL-ACC-001)

Checks that every AI application repository contains a registered ai-project-manifest.yaml declaring project owner, risk tier, models used, and business purpose.

Enforcement: Prevents "shadow AI" projects from being created silently.
